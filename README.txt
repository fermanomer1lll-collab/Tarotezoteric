4. Перетащите ВСЁ содержимое папки Tarotezoteric-site:
   - index.html

КАК ВКЛЮЧИТЬ GITHUB PAGES
-------------------------
1. В репозитории откройте Settings.
2. Слева выберите Pages.
3. В разделе Build and deployment:
   Source → Deploy from a branch
4. Branch → main
5. Folder → / (root)
6. Нажмите Save.
